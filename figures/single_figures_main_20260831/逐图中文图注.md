# B4 主报告逐图中文图注

## 图 01｜T287 量子探针读出状态时间序列

T287 真机 78 个量子探针快照中的 all-zero 与 all-one 读出错误概率。阴影表示各测量点的 shot-noise floor，全部 78 个快照均保留，无排除。该图证明云 API 用户位可构造随时间变化的量子测量状态，但本图本身不作漂移显著性判断。

数据：`01_t287_readout_proxy_timeseries.source.csv`，n=78，0 exclusions。

## 图 02｜T287 测量定义的有效场状态

由三时点 Y/Z 测量反演得到的 Effective H1 与 Effective H2 时间序列，误差棒保留测量 shot uncertainty。H1/H2 是量子测量定义的环境代理，而不是温度、电磁传感器读数，也不等同于底层脉冲标定参数。

数据：`02_t287_effective_field_state.source.csv`，n=78。

## 图 03｜E0 阴性对照结构函数

T287 E0 all-zero 通道的去偏结构函数与 shot-noise floor。冻结方差门 n=30、p=0.6497，未触发漂移判定。该阴性对照表明分析流程不会把所有时间波动都误判为过程漂移。

数据：`03_t287_e0_negative_control_structure_function.source.csv`，13 个结构函数滞后格。

## 图 04｜E1 信号通道结构函数

T287 E1 all-one 通道的去偏结构函数与 shot-noise floor。冻结方差门 n=30、p=2.79e-289，检测到超过 shot-noise 的过程方差。漂移检出是后续校准更新间隔经济学的进入条件。

数据：`04_t287_e1_drift_structure_function.source.csv`，13 个结构函数滞后格。

## 图 05｜E1 残差—更新间隔经济曲线

E1 通道在不同校准更新间隔下的 OU 点估计残差、非参数敏感性残差和无感知过程方差。OU 点估计给出 T*=134 s；bootstrap 95% CI 为 101–4000 s，且上界撞到观测窗，因此当前冻结结论为 `INCONCLUSIVE`。灰色区域表示 8–60 s 的当前可达控制区间。

数据：`05_t287_e1_interval_economics.source.csv`，400 个间隔网格点；关键参数见同编号 `summary.csv`。

## 图 06｜T* 与云 API 控制 floor

云 API 接口延迟 P50=12.4 s、P90=14.7 s、协议可达 floor=60 s，与内禀 T* 的 bootstrap 95% CI=101–4000 s 的对比。平台能够响应并不等于最优间隔已经被识别；当前只能客观报告 `INCONCLUSIVE`。

数据：`06_t287_tstar_vs_control_floor.source.csv`，4 个控制预算/参数条目。

## 图 07｜T176 真机 Session 0 逐 pair 端点

T176 真机 Session 0 中 20 个完整 slow/fast cadence pairs 的端点平方残差。每条线代表一个注册 pair；绿色向下表示 fast cadence 残差更低。14/20 pairs 改善，mean(fast)/mean(slow)=0.36165，即描述性降低 63.8%。所有完整 pairs 均保留。

数据：`07_t176_hardware_pair_slopegraph.source.csv`，n=20，0 exclusions。

## 图 08｜T176 真机 pair 改善幅度

同一批 20 个真机 pairs 的 log2(slow/fast)。正值表示 fast 优于 slow；14 个为正、6 个为负。该图用于展示效应异质性，避免把总体均值收益夸张为每一个 pair 都改善。

数据：`08_t176_pair_benefit_distribution.source.csv`，n=20。

## 图 09｜T176 冻结顺序累计比值诊断

按冻结 pair 顺序累计计算 mean(fast)/mean(slow)。中间轨迹仅作为 post-hoc 顺序诊断；唯一正式检验点为最终 n=20。最终 ratio=0.36165，低于冻结 critical ratio=0.49341，pair 内置换 p=0.0052。

数据：`09_t176_cumulative_ratio.source.csv`，n=20。

## 图 10｜T176 真机冻结置换零分布

基于全部 20 个 T176 真机 pairs 的 20,000 次 pair 内标签交换。红线为观测 ratio=0.36165，橙色虚线为 5% critical ratio=0.49341；冻结置换 p=0.0052。置换次数和随机种子均在同编号 `summary.csv` 与总 manifest 中记录。

数据：`10_t176_hardware_permutation_null.source.csv`，n=20,000；seed=20260815。

## 图 11｜基线漂移形状敏感性

Primary hybrid 以及 early saturating transient、linear ramp、step at block boundary 三种漂移形状敏感性中，观测比值均位于各自冻结临界值左侧。该图属于 simulation-assisted / post-hoc 稳健性证据，不能把缺失的 hardware Session 1 转化为真机证据。

数据：`11_baseline_drift_sensitivity.source.csv`，4 个分析条件。
