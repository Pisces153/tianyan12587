## 1. B-4 是什么

### 1.1 一句话主张（冻结版，写进预注册）

> 首次从商用云 API 用户位测量校准感知的统计经济学：逐通道漂移结构函数（解析精确去偏）、
> 感知预算 go/no-go 判据与感知值得性地图，经内置零对照通道、受控注入节奏对闭环、
> 冻结方法跨设备复制三重检验。

不许写的"首次"：首次自适应校准（Marciniak 占）、首次漂移统计刻画（Allan 是 Marciniak 的）、首次探针反馈（spectator 线占）、首次校准决策规则（Google Optimus 占）。详见 §6.3。

### 1.2 四部件

| 部件 | 内容 | 押注结果/要素 |
|---|---|---|
| **① SF 仪器** | 逐通道漂移结构函数 SF(τ)，二项噪声解析精确去偏，lag 轴 23 s – 数天，双后端 | 要素②③（③-弱口径） |
| **② 判据 + 地图** | σ_res²(T) = pq/(R·T) + (1/T)∫₀ᵀSF(t)dt，逐通道 T*_c 与最小残差，对照实测接口节奏分布，输出"值得感知/不值得"地图；e0 通道 = 预注册阴性预测 | 要素⑥、结果1（重定义版） |
| **③ 节奏对活闭环** | 受控注入已知漂移过程，同日 T_fast/T_slow 两节奏闭环，真实随机接口延迟，镜像指标配对；预测残差差匹配解析曲线 | 要素①⑤、结果2 |
| **④ 冻结方法复制** | 方法在 T287 上冻结（代码+判据+预测），T176 数据密封采集、两段式预注册后解封确认 | 要素④、结果4 |

**分支无关性（设计核心）：** 接口底噪落在 T* 哪一侧都是结果 ——
- T_floor < T*：可以"骑在曲线上"，判据给出最优节奏且闭环验证之；
- T_floor > T*：云接口够不到最优节奏，地图量化差距与代价 —— 这本身就是感知经济学的主结论之一。
**两个分支的措辞都预注册**（T-B7）。

### 1.3 六要素映射

①在线决策（闭环块 shield+节奏选择）②量子态测量信息（Pauli/读出探针）③扰动提取与预测（SF+判据，③-弱冻结措辞见 HANDOFF §9）④跨设备迁移（冻结方法 T287→T176）⑤动态控制闭环（注入-感知-补偿-任务指标回升）⑥突破静态校准（go/no-go 地图 vs 固定日历，逐通道给出静态策略的量化代价）。

### T-B1 功效模拟 + size 检验（唯一科学门）

**目的：** B-4 的 U 曲线/T* 子主张能不能在 3 天设计下成立。**这是 4 档与 3.5 档之间唯一的科学门。** 结构沿用 `docs/T7_SIM_V2_WORK_ORDER_20260803.md` 的纪律（报 size 不只报 power、无 oracle 条款、核 latent），对象换成 B-4 设计。

**新建：** `scripts/simulate_b4_design_power.py`

**DGP 集（每个 cell ≥1000 序列）：**
- `null_flat`：δ=0，纯二项 shot 噪声 —— **size 检验主角**
- `ou`：τ_c ∈ {10, 15, 30, 60} min × Var_proc ∈ {2e-4, 6.1e-4, 1.2e-3}
- `pink`：OU 叠加近似 1/f（照 Magann Eq. E2 的铺法，κ 系数按 10^(i/4)）
- `step_calendar` / `step_triggered`：事件型（只用于确认判据地图不会把事件误读成连续漂移）
- `step_as_ramp_artifact`：误规格对照（坑 19 —— 台阶穿成斜坡的老 bug 必须有专门 cell 防）

**模拟的采样设计必须逐字节等于 T-B3 的真实设计：** job 内 lag {23,46,67 s}、session 内 burst {0,1,2,4,8,16 min}、3 天、跨日 lag、16384 shots、二项抽样。吞吐率按 490 和 1000 两档各跑一遍。

**受检管线：** T-B4 的真实代码（import 同一模块，不许在模拟里重写一份估计器）。

**终点（每个都要 size 和 power 两个数）：**
1. **内点最优检验 size：** P(在 `null_flat` 下宣称存在内点 T*) ≤ 0.05。δ=0 时 SF=0，σ_res² 曲线单调降 —— 任何内点宣称都是假阳。**这一条不过，方法死，直接写成 headline，不许找能过的 cell。**
2. **T* 恢复 power：** 在 ou@实测参数（τ_c 15–30 min，Var_proc 6.1e-4）下，P(T̂* 的 CI 落在真值 2 倍以内) ≥ 0.8。
3. **判据地图错误率：** P(e0 型通道被判"值得感知") ≤ 0.05；P(e1 型通道被判"值得") ≥ 0.8。
4. **节奏对分辨力：** 注入已知 SF 下，P(fast/slow 残差比 CI 排除 1) ≥ 0.8；无注入下 ≤ 0.05。
5. 事件型 DGP 下判据不产生"连续漂移可感知"误报。

### T-B4 SF 估计器 + 判据模块（分析核心）

**新建：** `src/adaptive/sensing_economics.py` + `scripts/analyze_sensing_economics.py`

**内容：**
1. **精确去偏 SF**：SF̂(τ) = mean[(x_{t+τ}−x_t)²] − (σ̂²_{t+τ} + σ̂²_t)，σ̂² = p̂(1−p̂)/(N−1)·N/N… 用无偏修正 p̂(1−p̂)·N/(N−1) / N。逐通道、逐 regime、逐后端。lag 分箱按实测时间差。CI 用参数化 bootstrap（二项层 + 过程层）。
2. **残差-更新间隔曲线**：σ_res²(T) = p̄q̄/(R_eff·T) + (1/T)∫₀ᵀ SF(t)dt。SF 的 ∫ 用两套：OU 拟合参数化 + 非参单调插值,两套都报（敏感性）。R_eff 用 dry-run 实测吞吐。T* 解析求 + 数值求,**不许硬编码 35 s**。
3. **go/no-go 判据**：通道值得感知 ⟺ (a) 检测门过：卡方对已知 σ²（HANDOFF §13 那条,df 单边无限）给出 Var_proc CI 下界 > 0；(b) 经济门过：min_{T≥T_floor} σ_res²(T) < Var_proc（不感知的残差就是过程方差本身）且 CI 分离。T_floor = dry-run 实测接口底噪分布的 P50/P90 两档都报。
4. **感知值得性地图**：逐通道 × 逐后端表：Var_proc、τ_c、T*、min σ_res²、T_floor、verdict、CI。
5. 判据最终数学形式以 T-B1 模拟验证过 size 的版本为准冻结。

**验收（v3 回归测试,冻结前必须全过）：** 在冻结 v3 语料上复算,必须复现 [前会话核出] 的四个结果（容差内）：
- SF 25 min 以上平,幂律 α = −0.079 ± 0.088
- job 内/跨 snapshot 方差比 1.15 / 12.21
- e0 判"不值得连续感知"、e1 判"值得"（或至少检测门 e0 阴 e1 阳）
- 事件台阶 +0.02537 ≈ 2.9× 底噪,且被归入事件表征不进 SF
复现不了 → 先找出是新代码错还是前会话错,报告,不许硬调容差。

**禁止：** 任何绝对数字阈值（阈值全部相对解析底噪或 CI,见 §6.2）；`scenario ==` 零命中同样适用于本模块。

### T-B5 节奏对活闭环块（要素①⑤,结果2）

**目的：** 用受控注入 + 真实随机接口延迟,在真机上验证判据曲线的可操作面。**杀死"回放 ≡ 闭环"的自证问题：延迟是真排队,不是模拟的。**

1. **注入过程**：h1/h2 上程序化离散 OU,τ_inj ≈ 5 min,σ_inj 由 T-B1 模拟定标（目标：每 update 漂移量 ≈ 2–3× T_fast 下感知噪声）,硬клип |δ| ≤ 0.08（门控阈 0.10 之下,保证补偿路径真执行）。RNG seed 写进冻结 config,注入日志密封。
2. **同日节奏对**：每天两个子块,T_fast 与 T_slow（临时值 90 s / 360 s,**T_fast ≥ 2× 实测接口底噪 P90,T-B6 后定**）。子块顺序隔日交替（day1 fast先,day2 slow先）杀 session 内趋势混淆。每子块:感知→shield→数字逆补偿→镜像探针,循环。
3. **门控幅度阶梯并入**（HANDOFF §4.2 改造版）：每天块尾加一个单点门控测试,幅度按日 0.05 / 0.10 / 0.25 —— 三档要三种行为（放行/弃权或降幅/必须弃权）。单点,便宜,不与节奏对混淆。
4. **终点**：主 = 配对镜像 success_probability 亏损 fast vs slow + 追踪残差对解析预测曲线的匹配（预测数值在开采前算出并写进预注册）。副 = 门控三档行为记录。
5. **措辞红线**：这是**受控注入下的节奏经济学验证**。不得称自然漂移、不得写"跟踪自然漂移"。

2. **接口底噪分布**：连发 10 个最小探针 job,量提交→结果往返分布（P50/P90）。这是 T_floor 和 T_fast 下界。
3. **T176 终核**：1 个探针 job 过全链（账号、配额、字段、物理链跨日固定性、calibrationTime 可取）。
4. **镜像深度阶梯**：扫 d,选 success_probability ∈ [0.3, 0.7] 的 d,写进预注册。

**失败分支：** T176 任何一环不过 → 结果4 降级"冻结方法单设备 + 仿真→真机迁移",立刻报告,不自行找替代。
