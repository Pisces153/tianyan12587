## 2. 本会话的核心发现

### 2.1 占用模型一直是错的 **[核过 — 反解自 Murphy 口述]**

Murphy 说:「实验室每次只给 20 分钟,跑 74 个采集要两天」。反解:

```
74 collections / 2 sessions = 37 per session
37 × 33 settings × 1024 shots = 1.25M shots / 20 min
→ 有效吞吐 ≈ 1 kHz(不是旧 HANDOFF 假设的 2–5 kHz)
→ 每 session 预算 ≈ 1.27M shots
→ 3 天 = 3 sessions ≈ 3.8M shots 总共
```

**旧 HANDOFF §4.3 写「上限 2.5e8 shots,预算不是约束」。在真实占用模型下这是错的。**
真实总预算 **3.8M**,差 66,000 倍。

更要紧:旧轨 A 计划 84 snapshots × 33 × 16384 = 4.54e7 shots
= **36 个 session = 36 天**。
**那份 21 天日历在被砍之前就已经超了 1.7 倍不可行。** 砍到 3 天只是让它显形。

⚠️ 这个 1 kHz 是从一句口述反解的。**dry-run 第一件事就是实测它。**

### 2.2 3 天买得到什么、买不到什么 **[推导]**

shots 和点数在总预算固定时可换(16 点 @1024 ≈ 1 点 @16384)。
所以怎么切都一样,结论只看**单位时间总 shots**。

```
每天 1.27M shots 全押 ③ 的 2 个读出探针
→ 每天一个 level 估计,σ = sqrt(0.086×0.914/635000) = 0.00035
```

| 要做的事 | 3 天能不能 |
|---|---|
| **检出**漂移(日间增量 0.0055–0.010 vs σ_inc≈0.0005) | **SNR 11–20,白送** |
| 体制内是否有真结构(卡方对已知 σ²) | **能。见下** |
| **预报**(需要 origin 数) | 2 个增量。**不可能** |
| 分辨"性能触发式" vs "按排程"重标定 | 需 ≥3 事件,3 天期望 ~1 个。**不可能** |

**⇒ ③-强 在 3 天内数学上不可达。不要再为它设计任何东西。**

### 2.3 3 天真正买到的东西:体制内结构的决定性检验 **[推导]**

旧 HANDOFF §2.5 那个 F=1.357 / p≈0.15 的问题,在 3 天 + 16× 下变成决定性。

**关键:σ² 是解析已知的**(`sqrt(p(1-p)/N)`,`environment_proxy.py:64-66` **[核过]**),不是估出来的。
所以不用 F 检验(两个估计方差比,df 两边都有限,弱),
用**卡方检验对已知 σ²**(df 一边无限,强):

```
探针拆绑 + 25 min 节奏 + 16384 shots → 3 天 173 个点,σ=0.0022
体制内 115 点,proc_sd=0.0051 假设:
  观测 var / σ² = 6.37
  chi2 = 115 × 6.37 = 726     临界 ≈ 140
  p < 1e-50
可检出下限:proc_sd ≈ 0.001
```

**这是 21 天也给不了的东西。** 21 天买事件数(③-强),3 天+16× 买体制内分辨率。
Murphy 砍掉的是前者,后者还在。

### 2.4 一个设计错误,可以现在修:探针拆绑 **[核过 + 推导]**

**[核过]** ③ 的观测量是 `readout_probes` 固定位 {10, 21},**33 个 setting 里的 2 个**
(`drift_campaign_v3.py`,`environment_proxy.py:299`)。这 2 个和另外 31 个绑同一节奏。

但③只要这 2 个。拆开算 **[推导]**:

50 min 节奏 = 29 轮/天 ≈ 16 min/天  ← 可行

**③ 的时间分辨率从 4/天 提到 29/天,不多花钱。**

### 4.3 shot 阶梯不变性实验(零额外机时,主方法学交付)

**嵌套子采样:采一次 16384,白拿整条 shot 阶梯。**

16384 的 counts 里**超几何**抽 1024/4096(不是重采样 —— 是「若当初只采 1024」的精确模型;
shots 在一个 setting 内可交换,16384 @1kHz = 16 s,期间不漂)。

一份数据出三个数:

| shots | 朴素 skill vs persistence | 去偏 skill |
|---|---|---|
| 1024 | ≈ +0.45(地板) | X |
| 4096 | ≈ +0.48 | X |
| 16384 | 真值 | X |

**朴素的随 shots 爬,去偏的三档同一个 X。这就是证明。**

**这个实验无论有没有真漂移都成立:**
δ=0 → X≈0 而朴素爬到 +0.5;δ>0 → X 三档一致为正。**两条路都证明了方法。没有空手的分支。**

而且它是 **session 内实验**,不需要跨日 origin。20 min 里能拿 ~36 个 16384 点,
3 个 session 共 ~108 个 origin。**机时砍到 3 天没伤到它。**

### 5.2 不构成威胁的
