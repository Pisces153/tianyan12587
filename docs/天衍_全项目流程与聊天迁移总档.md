## 2. 项目主叙事

项目最初的核心问题是：量子硬件在温度、电磁干扰、噪声和运行漂移下，能否通过局部测量和 AI 推理实现安全的自适应校准，而不是只做一次静态校准。

目标链条被多次写成：

`局部 Pauli 测量 → 有效参数/漂移状态反演 → 不确定性判断 → 补偿或探测决策 → 再测量 → 任务指标恢复 → 数据回流与跨设备/跨 patch 迁移`

项目中的 AEMTN 至少包含两层，必须分开写：

1. **论文/主模型 AEMTN-core**：以局部 `Pauli` 测量轨迹和已知控制量 `t` 为输入，估计有效 `h1/h2/Jz` 及不确定性。
2. **完整自适应校准系统**：还需要漂移感知、预测、shield、策略/调度、补偿执行和任务指标闭环。主模型本身不能被包装成已经完成了全部系统。

最重要的边界是：`h1/h2` 在当前协议下相对可辨识，`Jz` 弱可辨识；因此早期方案把 `Jz` 排除在自动补偿之外，要求不确定性门控拒绝对弱可辨识量做自动校准。

### 3.9 B4 离线功效与 fixed-overhead 根因

早期 B4 只用吞吐 `R` 模拟设置时间，Claude 审计发现缺了固定开销 `c`。修正为：

`setting_time = shots / R + c`

之后：

- 15 格 timing lookup 形成冻结查表；6 格满足全部预设条件。
- 非单调被解释为真实的“每 shot 速率 vs 每 setting 固定开销”权衡，不再假设吞吐越高越好。

### 3.12 端点错配与修正采集方案

最后一轮审计找到了 B4 最关键的科学/工程根因：

- 功效层向 `cadence_ratio_gate` 输入的是逐 cycle 的 `residual²`。
- 旧真机分析向同一个 gate 输入的是 raw mirror loss。
- raw mirror loss 含约 `L0=0.6455` 的加性电路误差底座，导致节奏效应被稀释到约 `0.071–0.072%`。
- 实测 ratio 的统计误差约 `0.005625`，80% MDE 约 `1.58%`；实际效应比 MDE 小约 `22×`，不是简单增加 shots 就能补救。
- 旧 `24` 行配对实际是 mirror replicate：fast 每块约 6 cycles，slow 每块约 1 cycle；预注册所需的逐 cycle residual² 端点在这份数据中不可计算，slow 有效数仅 `n=3`。
- `n=3` sensitivity 的区间不能升格为档 4 证据；也不能为改善结果剔除极端点。

正确修正：

1. `cadence_ratio_gate` 和核心冻结模块不改。
2. 主端点改回预注册的逐 cycle、同 session 配对 residual²；raw mirror loss 降为 QC/描述性读数。
3. 每个 pair 按 cycle 数定义，不按固定块时长定义；目标 `n_fast=n_slow=24`。
4. fast/slow 必须在同一 session；块未完成或跨 session 则整块非裁决。
5. 3600 s 禁止开始新的 sensing cycle；4500 s 窗要求 loop+mirror 的 `runStartTime` 都在同一完整窗口内。
6. 修正轮计划为 48 cycles、24 pairs、288 tasks、983,040 shots；离线预飞使用 `R=1486.09,c=6.99,seed=20260806`，得到 `size=.000,power=.910`。

修正预飞最终停在真机前：32 项相关测试通过、manifest/hash 通过、Stage-1 时间戳回放 48/48、旧数据最终 `INCONCLUSIVE`；没有启动新的 hardware runner，也没有提交修正轮。
